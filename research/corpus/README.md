# Local reference assets

Downloaded or user-supplied scores, MIDI, and audio live here for analysis. Raw files are ignored by Git and never placed in the application `public/` directory. The versioned source register is `docs/research/corpus-candidates.json`; analyses record the local asset hash so another session can verify the same edition.

Public access to a file does not establish permission to redistribute it. Keep artist identity, work, edition or arranger, referring URL, direct asset URL, retrieval date, and any known license with each source record. Missing assets after a fresh checkout are an acquisition task, not evidence that an analysis was rerun.
